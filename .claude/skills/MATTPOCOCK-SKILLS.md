# Matt Pocock's agent skills (vendored)

The skill folders in this directory are unmodified copies from https://github.com/mattpocock/skills
(plugin version 1.3.2, commit 5863806dd4e15c63174bee4e7515a4256792ecfa, copied 2026-11-14). They are the 27 skills the plugin ships:
the `engineering` and `productivity` buckets.

To update: re-copy the folders from a newer checkout of that repository.
