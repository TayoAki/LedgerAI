# Ledger is software for bookkeeping Firms, not a bookkeeping service

The code we started from was built for one firm serving its own Clients, which made two businesses possible: sell bookkeeping to small businesses and keep Ledger as the internal tool, or sell Ledger itself to bookkeeping Firms. We chose to sell the software. Each Firm subscribes, gets its own workspace and Client portal, and its own accountant gives the financial sign-off, so Ledger never employs the reviewer or takes responsibility for a Client's books.

## Consequences

Everything that assumes a single firm (one workspace, one owner, sign-in through one hosting platform, agents run from one person's account) has to become per-Firm.
